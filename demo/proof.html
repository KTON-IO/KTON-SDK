Wallet proof test

How to use

1. If a wallet is already connected, disconnect it, then connect again: the ownership proof is asked for while connecting.

2. Press "Sign a test text" and approve it in the wallet.

3. Press "Copy result" and send the text back.

Nothing here moves funds. The wallet only signs a random text made on this page.
